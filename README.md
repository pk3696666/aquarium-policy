## ❓ 常見問題 (FAQ)

### Q1: 為什麼 App 需要要求「相機」權限？
* **回答**：本 App 內建的「試紙相機掃描」功能需要使用您的相機，協助拍攝水質測試紙的顯色狀態，以便為您自動預填 pH、NO2、NO3 等關鍵數據，省去手動打字的時間。
* **隱私聲明**：我們極度重視隱私。相機僅在拍照當下作本地色彩分析，影像**絕對不會**儲存至您的相簿，也**絕對不會**上傳至任何外部伺服器。

### Q2: 試紙拍照掃描不夠準確時該怎麼辦？
* **回答**：環境光源（太暗、太亮或有色偏的燈光）可能會對相機色彩辨識造成干擾。本 App 在掃描結果頁面提供極為直覺的**微調選單 (Picker)**，若辨識有少許落差，您可以點擊並手動微調至正確數值後再進行儲存。

### Q3: 數據有提供雲端同步嗎？
* **回答**：**有的！** 本 App 支援 Apple 的 **iCloud 雲端同步**服務。只要您的裝置登入同一個 Apple ID 並啟用了本 App 的 iCloud 權限，您的所有魚缸數據與日誌都會安全且自動地在您的多部 iOS 裝置（如 iPhone 與 iPad）之間同步，完全不需要額外手動備份。
