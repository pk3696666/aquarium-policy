## ❓ よくある質問（FAQ）

### Q1：なぜアプリは「カメラ」の権限を求めるのですか？
* **回答**：「試験紙カメラスキャン」機能では、水質試験紙を撮影するためにカメラへのアクセスが必要です。これにより、pH、NO2、NO3 などの主要な数値を自動的に入力でき、手入力の手間を省けます。
* **プライバシーについて**：プライバシーを重視しています。カメラはリアルタイムで色を解析するためだけにローカルで使用されます。**画像が写真アプリに保存されたり、外部サーバーにアップロードされることは一切ありません。**

### Q2：カメラスキャンの精度が 100% でない場合はどうすればよいですか？
* **回答**：周囲の照明（黄色い光や暗い環境など）が色の認識に影響することがあります。精度を確保するため、アクアマスター日誌にはスキャン結果画面に直感的な**調整機能**が搭載されています。保存前に、お手持ちのカラーカードに合わせて数値を手動で簡単に調整できます。

### Q3：水槽データはクラウドに同期されますか？
* **回答**：**はい！** アクアマスター日誌は、Apple の**iCloud CloudKit 同期**技術に完全対応しています。同じ Apple ID でサインインし、本アプリの iCloud 権限が有効になっていれば、水槽データ・ログ・ルーティンはすべて自動的かつ安全にお使いの iOS デバイス間（iPhone と iPad など）で同期されます。手動でのバックアップは不要です。
